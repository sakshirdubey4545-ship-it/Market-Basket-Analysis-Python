# 🛒 Market Basket Analysis using Python

## 📌 Project Overview
This project analyzes customer purchase transactions to identify frequently bought-together products using Market Basket Analysis. The insights help improve cross-selling, product bundling, and business decision-making.

## 🛠 Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## 📊 Key Features
- Data Cleaning & Preprocessing
- Exploratory Data Analysis (EDA)
- Purchase Pattern Analysis
- Product Association Analysis
- Data Visualization

## 📈 Key Insights
- Identified frequently purchased product combinations.
- Generated recommendations for cross-selling and product bundling.
- Supported data-driven business decisions.

- Jupyter Notebook (.ipynb)
- Project Report (.pdf)
- Dataset (.csv)
